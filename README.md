# CodeForge AI 🚀

CodeForge AI is a full-stack AI-powered collaborative coding platform designed for developers to write, execute, and collaborate on code in real time. The platform provides secure authentication, live coding rooms, problem-solving support, and AI-assisted development features through an interactive and modern interface.

Built using React, Vite, Node.js, Express, Socket.io, and JWT authentication, the project focuses on scalable backend architecture, real-time communication, and seamless frontend experience. It demonstrates concepts of full-stack development, distributed collaboration, API integration, and modern software engineering practices.

## Features

* Real-time collaborative coding
* Secure JWT-based authentication
* AI-assisted coding support
* Live coding rooms using Socket.io
* Responsive frontend interface
* RESTful backend APIs
* Protected routes and user sessions
* Modular frontend and backend architecture

## Tech Stack

* Frontend: React, Vite
* Backend: Node.js, Express
* Real-time Communication: Socket.io
* Authentication: JWT, bcrypt
* Database/Storage: LowDB (JSON-based)
* AI Integration: Gemini API

## Setup

Before running the project, create a `.env` file and add your own API credentials:

```env
GEMINI_API_KEY=your_api_key_here
JWT_SECRET=your_secret_here
```
